# Createch Hobbies

**Live site:** [https://createch-hobbies.co.ke](https://createch-hobbies.co.ke)

Online shop for DIY STEM assembly kits for children, based in Nairobi, Kenya. Customers browse kits, check out, and pay with M-Pesa.

**Stack:** Next.js 15 (App Router), React 19, TypeScript, and Tailwind CSS. The catalog, orders, and customer accounts come from WooCommerce.
